# 🍱 Food Waste Reduction Platform

A full-stack MERN (MongoDB, Express, React, Node.js) web application designed to reduce food waste by connecting **food donors**, **NGOs**, and **administrators** on a single digital platform. The system enables efficient food redistribution and helps ensure that surplus food reaches those in need.

---

## 📌 Project Overview

Food waste is a major global issue. This platform provides a centralized solution where:

- 🍽️ Food Donors can list excess food items
- 🤝 NGOs can request and collect food donations
- 🛡️ Administrators can monitor, verify, and manage all activities

The system ensures smooth communication, transparency, and efficient food distribution.

## 🧠 System Modules

   - Add food details

2. **NGO Module**

   - Send food requests

3. **Admin Module**
